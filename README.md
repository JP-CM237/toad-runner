This is a simple-to-play 2D platformer 2d game where you collect apples and avoid enemies till the end of the game, and go to the next level when you complete one


Controls to play the game
Left: left arrow key, A key (keyboard)
Right: right arrow key, D key (keyboard)
Jump: up arrow key, space bar, W key (keyboard)
Pause game: Esc key (keyboard)
